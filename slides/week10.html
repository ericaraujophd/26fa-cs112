The Same Thing, Smaller

Open the doll, find a smaller doll, until one is too small to open.

A Function That Calls Itself

The sum of an array is the first item plus the sum of the rest.


int sum(int a[], int size) {
    if (size == 0) {
        return 0;          // no items: the sum is 0
    }
    return a[0] + sum(&a[1], size - 1);  // first + the rest
}

&a[1] is the array starting one item later: the rest.

How to Write One

1. The base case

An instance so small the answer needs no work.
Often n == 0 or n == 1.

2. The recursive step

Solve the general case by using the answer to a smaller one.
For f(n), often f(n - 1).

Every call must get closer to the base case.

Factorial

n! = n × (n − 1)!    0! = 1! = 1


unsigned factorial(unsigned n) {
    if (n <= 1) {
        return 1;                   // base case
    }
    return n * factorial(n - 1);    // recursive step
}

Recursion Is Not Free

Recursive


int sum(int a[], int size) {
    if (size == 0) {
        return 0;
    }
    return a[0] + sum(&a[1], size - 1);
}

O(n) time, n frames on the stack

Iterative


int sum(int a[], int size) {
    int result = 0;
    for (int i = 0; i < size; ++i) {
        result += a[i];
    }
    return result;
}

O(n) time, one frame

When Recursion Is the Better Tool

Print a singly-linked list backwards. A loop has to walk from the front for every item: O(n²).


template<class Item>
void List<Item>::Node::printReverse(ostream& out) const {
    if (myNext != nullptr) {
        myNext->printReverse(out);    // the nodes behind me first
    }
    out << myItem << ' ';           // then me
}

One pass, O(n). The run-time stack remembers the way back.

Towers of Hanoi

Move every disk from A to B, one at a time.
Never put a larger disk on a smaller one.

Can We Spot a Pattern?

3 disks

4 disks


move(3, src, aux, dest);
move(1, src, dest, aux);
move(3, aux, dest, src);
move(n - 1, src, aux, dest);  // the top n - 1, out of the way
move(1, src, dest, aux);        // the biggest, to its place
move(n - 1, aux, dest, src);  // the n - 1, back on top

Hanoi, Recursively


void move(int numDisks, char src, char dest, char aux) {
    if (numDisks == 1) {                                    // base case
        cout << "Move top disk from " << src << " to " << dest << endl;
        return;
    }
    move(numDisks - 1, src, aux, dest);   // the smaller tower, out of the way
    move(1, src, dest, aux);              // the biggest disk
    move(numDisks - 1, aux, dest, src);   // the smaller tower, back on top
}

int main() {
    move(4, 'A', 'B', 'C');
}

Merge Sort


void mergeSort(int a[], int n) {
    if (n <= 1) {
        return;              // base case
    }
    int half = n / 2;
    mergeSort(a, half);                // left half
    mergeSort(&a[half], n - half);     // right half
    merge(a, half, n);                 // merge them
}

Week 10 Recap

  • A recursive function needs a base case and a step that gets closer to it
  • Every call gets a frame on the run-time stack
  • The work happens as the frames come back off: unwinding
  • Towers of Hanoi: 2n − 1 moves, O(2n)
  • Selection and insertion sort: O(n²); insertion sort is O(n) on sorted input
  • Merge sort recurses: O(n lg n)
