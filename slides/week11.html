Height

The number of nodes on the longest path from the root down. An empty tree: 0. One node: 1.

height1234h
nodes in a full tree137152h − 1

So n nodes fit in a tree about lg n tall, if it is full.

The STL set and map

the library's BST, finished and balanced

set


#include <set>

set<string> fruit;
fruit.insert("pear");
fruit.insert("apple");
fruit.insert("pear");                    // already there: nothing happens
cout << fruit.size() << endl;           // 2
cout << fruit.count("apple") << endl;   // 1: it is there
  • Each item once.
  • Kept in sorted order.
  • An item cannot be changed in place: that could break the order.

Week 11 Recap

  • Smaller items go left, bigger right, for every node
  • insert and contains are the guessing game: compare, then go one way
  • New nodes always arrive as leaves
  • The cost is the height: lg n when bushy, n when a list
  • Inorder comes out sorted; the destructor is postorder
  • Removing a node with children: copy in the largest on its left
  • set and map are balanced BSTs: O(lg n), always
